# Allumeria-VeinMiner-Mod

An ore vein excavation mod for Allumeria on the Ignitron mod loader: https://codeberg.org/ignitron/ignitron

### Features
* Hold `V` while mining any ore to instantly mine all connected blocks in the vein (up to 64 blocks per strike).
* Mined ores are delivered straight into your inventory (or dropped at your feet if full) so drops never get lost in walls.
* Supports all vanilla and modded ores.
* Displays a `Vein Miner` indicator above your hotbar when holding the key.

### Installation
1. Install the Ignitron mod loader: https://codeberg.org/ignitron/ignitron
2. Download `veinminer.zip` from the [Releases](https://github.com/legendarynugget/Allumeria-VeinMiner-Mod/releases) tab.
3. Extract the `veinminer` folder into your `Allumeria/mods/` directory.
